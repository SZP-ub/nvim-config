下面详细介绍 shell 脚本文件的书写格式：

---

## 1. 文件扩展名

- 通常以 `.sh` 结尾（如 `myscript.sh`），但不是强制要求。

---

## 2. 首行（Shebang）

- 第一行通常写为：
    ```sh
    #!/bin/bash
    ```
    或
    ```sh
    #!/usr/bin/env bash
    ```
    这表示脚本由哪个解释器执行（如 bash、sh、zsh 等）。

---

## 3. 注释

- 以 `#` 开头的行为注释，不会被执行。

    ```sh
    # 这是一个注释
    ```

- 以 `:<<!`

    `!`中间部分的行为注释，不会被执行。

    ```sh
    :<<!
    # 这是多行注释
    # 这是多行注释
    !
    ```

---

## 4. 命令与语句

- 每行写一条命令，按顺序执行。
    ```sh
    echo "Hello, world!"
    ls -l
    ```

---

## 5. 变量定义与引用

下面详细介绍 shell 脚本中的**变量定义与引用**，包括全局变量、局部变量、常量等内容：

---

## 变量定义与引用

### 1. 普通变量（全局变量）

- **定义方式**：变量名=值，等号两边不能有空格。
    ```sh
    name="Tom"
    age=18
    ```
- **引用方式**：用 `$变量名` 或 `${变量名}`。
    ```sh
    echo "My name is $name, age is ${age}"
    ```
- **作用范围**：在脚本中定义的变量，默认是全局变量，整个脚本都可以访问。

---

### 2. 局部变量

- **定义方式**：在函数内部用 `local` 关键字声明。
    ```sh
    myfunc() {
      local var="I am local"
      echo "$var"
    }
    myfunc
    # echo $var  # 这里访问不到 var
    ```
- **作用范围**：只在函数内部有效，函数外无法访问。

---

### 3. 常量

- **shell 没有真正的常量**，但可以用 `readonly` 或 `declare -r` 让变量只读，不能被修改。
    ```sh
    readonly PI=3.14
    declare -r URL="https://example.com"
    # PI=3.15  # 会报错
    ```
- **用途**：防止变量被意外修改。

---

### 4. 变量赋值注意事项

- 等号两边**不能有空格**。
    ```sh
    var=123   # 正确
    var = 123 # 错误
    ```
- 变量名只能包含字母、数字和下划线，不能以数字开头。

---

### 5. 变量引用细节

- 推荐用双引号包裹变量，防止空格或特殊字符带来问题。
    ```sh
    echo "$name"
    ```
- 用花括号可以防止歧义：
    ```sh
    echo "${name}123"
    ```

---

### 6. 导出变量（环境变量）

- 用 `export` 导出变量，使其对子进程可见。
    ```sh
    export PATH="$PATH:/my/custom/path"
    ```

---

### 7. 变量的删除

- 用 `unset` 删除变量。
    ```sh
    unset name
    ```

---

**小结：**

- shell 脚本变量默认全局，函数内用 `local` 声明局部变量。
- 用 `readonly` 或 `declare -r` 声明只读变量（常量）。
- 变量引用时建议加双引号，避免歧义和错误。
- 用 `export` 可以让变量变为环境变量，供子进程使用。

在 shell 脚本中，有许多**特殊变量**，它们在脚本执行时自动赋值，常用于获取参数、进程信息、状态等。常见特殊变量及其含义如下：

---

| 变量      | 含义                                                   |
| --------- | ------------------------------------------------------ |
| `$0`      | 当前脚本的文件名                                       |
| `$1`~`$9` | 脚本的第1~9个参数（第10个及以上用`${10}`、`${11}`...） |
| `$#`      | 传递给脚本的参数个数                                   |
| `$*`      | 以一个字符串显示所有参数（不区分参数边界）             |
| `$@`      | 以各自独立的字符串显示所有参数（保留参数边界）         |
| `$$`      | 当前脚本的进程ID（PID）                                |
| `$!`      | 上一个后台运行命令的进程ID                             |
| `$?`      | 上一个命令的退出状态（0为成功，非0为失败）             |
| `$_`      | 上一个命令的最后一个参数                               |

---

### 示例

```sh
#!/bin/bash
echo "脚本名: $0"
echo "第一个参数: $1"
echo "参数个数: $#"
echo "所有参数(\$*): $*"
echo "所有参数(\$@): $@"
echo "当前进程ID: $$"
echo "上一个后台命令PID: $!"
echo "上一个命令退出状态: $?"
```

---

### 说明

- `$*` 和 `$@` 的区别：  
  在双引号中，`"$*"` 把所有参数当作一个整体，`"$@"` 把每个参数当作独立整体。
- `${10}` 表示第10个参数，不能直接用 `$10`。

---

这些特殊变量在编写 shell 脚本时非常有用，能方便地获取参数、状态和进程信息。

## 6. 输入与输出

- `echo` 或 `printf` 用于输出。
- `read` 用于读取用户输入。

---

## 7. 条件判断

```sh
if [ "$name" = "Tom" ]; then
  echo "Hello, Tom"
else
  echo "You are not Tom"
fi
```

---

## 8. 循环结构

- for 循环：
    ```sh
    for i in 1 2 3; do
      echo $i
    done
    ```
- while 循环：
    ```sh
    while [ $i -le 5 ]; do
      echo $i
      i=$((i+1))
    done
    ```

---

## 9. 函数定义

```sh
myfunc() {
  echo "This is a function"
}
myfunc
```

---

## 10. 脚本执行权限

- 保存脚本后需赋予可执行权限：
    ```sh
    chmod +x myscript.sh
    ```

---

## 11. 执行脚本

- 直接运行：
    ```sh
    ./myscript.sh
    ```
- 或用解释器运行：
    ```sh
    bash myscript.sh
    ```

---

## 12. 退出状态

- 用 `exit` 指定退出码，`0` 表示成功，非0表示失败。

---

**总结：**  
shell 脚本结构清晰，首行指定解释器，支持变量、条件、循环、函数、注释等，保存后赋予执行权限即可运行。
