# Vim 正则表达式完整指南（含详细例子与局部范围、前瞻、后顾）

## 1. 基本字符与特殊字符

| 字符      | 含义                           | 示例及说明                            |
| --------- | ------------------------------ | ------------------------------------- |
| `.`       | 匹配任意单个字符（不包括换行） | `/a.c` 匹配 `abc`, `a1c`，不匹配 `ac` |
| `*`       | 匹配前面的字符0次或多次        | `/ba*` 匹配 `b`, `ba`, `baa`          |
| `\+`      | 匹配前面的字符1次或多次        | `/ba\+` 匹配 `ba`, `baa`，不匹配 `b`  |
| `\=`      | 匹配前面的字符0次或1次         | `/ba\=` 匹配 `b`, `ba`                |
| `\{n,m}`  | 匹配前面的字符n到m次           | `/a\{2,4}` 匹配 `aa`, `aaa`, `aaaa`   |
| `^`       | 匹配行首                       | `/^abc` 匹配以 `abc` 开头的行         |
| `$`       | 匹配行尾                       | `/abc$` 匹配以 `abc` 结尾的行         |
| `[]`      | 匹配括号内任一字符             | `/[abc]` 匹配 `a`、`b`、`c`           |
| `[^]`     | 匹配不在括号内的任一字符       | `/[^0-9]` 匹配非数字字符              |
| `\|`      | 或操作                         | `/foo\|bar` 匹配 `foo` 或 `bar`       |
| `\(` `\)` | 分组                           | `/\(abc\)` 匹配 `abc`，用于分组引用   |
| `\n`      | 匹配换行符                     | `/foo\nbar` 匹配跨行的 `foo` 和 `bar` |
| `\_`      | 使`.`等可以匹配换行            | 匹配任意字符包括换行                  |
| `\d`      | 匹配数字，等价于 `[0-9]`       | `/\d\+` 匹配 `123`、`42`              |
| `\D`      | 匹配非数字，等价于 `[^0-9]`    | `/\D\+` 匹配 `abc`、`!@#`             |
| `\w`      | 匹配字母、数字、下划线         | `/\w\+` 匹配 `abc123_`                |
| `\W`      | 匹配非字母、数字、下划线       | `/\W\+` 匹配 `!@#`                    |
| `\s`      | 匹配空白字符（空格、Tab等）    | `/\s\+` 匹配空格、Tab                 |
| `\S`      | 匹配非空白字符                 | `/\S\+` 匹配 `abc123`                 |

## 2. 增删改查操作（含局部范围与单行）

### 2.1 查找

- `/pattern`：向下查找（如 `/hello` 查找下一个 `hello`）
- `?pattern`：向上查找（如 `?main` 查找上一个 `main`）
- `:g/pattern`：全局查找并列出所有匹配行（如 `:g/^#/` 查找所有以 `#` 开头的行）

#### 局部范围查找

- `:n,mg/pattern/`：在第 n~m 行查找匹配行
  例：`:10,20g/pattern/` 查找第 10~20 行中包含 `pattern` 的行

#### 单行查找

- `:n/pattern`：在第 n 行查找 `pattern`
  例：`:5/foo` 在第 5 行查找 `foo`。

---

### 2.2 替换

- `:s/pattern/replace/`：当前行替换第一个（如 `:s/foo/bar/`）
- `:s/pattern/replace/g`：当前行全部替换（如 `:s/foo/bar/g`）
- `:%s/pattern/replace/g`：全文件替换（如 `:%s/foo/bar/g`）

#### 局部范围替换

- `:n,ms/pattern/replace/g`：只在第 n~m 行替换
  例：`:5,15s/foo/bar/g` 只在第 5~15 行将所有 `foo` 替换为 `bar`
- `:'<,'>s/foo/bar/g`：只在选中行范围内替换

#### 单行替换

- `:n s/pattern/replace/`
  例：`:8s/abc/xyz/` 只在第 8 行将第一个 `abc` 替换为 `xyz`。

- 当前行用 `.` 表示
  例：`:.s/foo/bar/` 只在当前行替换第一个 `foo` 为 `bar`。

---

### 2.3 删除

- `:g/pattern/d`：删除所有匹配行（如 `:g/^$/d` 删除所有空行）

#### 局部范围删除

- `:n,mg/pattern/d`：只在第 n~m 行删除匹配行
  例：`:3,8g/^$/d` 删除第 3~8 行中的所有空行
- `:5,10g/^\/\//d`：只在 5~10 行删除所有以 // 开头的注释行
- `/v\d/d`：删除所有包含数字的行，保留不含数字的行

#### 单行删除

- `:n g/pattern/d`
  例：`:12g/foo/d` 如果第 12 行包含 `foo`，则删除第 12 行。

---

### 2.4 插入/追加

- `:g/pattern/normal o<text>`：匹配行下方插入（如 `:g/^func/normal o// new line`）
- `:g/pattern/normal O<text>`：匹配行上方插入（如 `:g/^main/normal O// main function`）

#### 局部范围插入

- `:n,mg/pattern/normal o<text>`：只在第 n~m 行匹配行下方插入
  例：`:20,30g/pattern/normal o// new line` 在第 20~30 行中所有匹配 `pattern` 的行下方插入 `// new line`

#### 单行插入

- 在第 n 行下方插入内容：
    ```
    :call append(n, '内容')
    ```
    例：`:call append(5, 'hello')` 在第 5 行下方插入 `hello`。

---

### 2.5 只对选中行（可视模式）

- 选中多行后，输入 `:`
- 会自动出现 `:'<,'>`
- 例：`:'<,'>s/old/new/g` 只在选中行范围内替换所有 `old` 为 `new`。

## 3. 分组与引用

- `\(` 和 `\)`：分组
- `\1`, `\2` ...：分组引用

**例子：交换两个单词顺序**

```vim
:%s/\(\w\+\)\s\+\(\w\+\)/\2 \1/g
```

- `hello world` 变为 `world hello`

**例子：将 `foobar` 替换为 `barfoo`**

```vim
:%s/\(foo\)\(bar\)/\2\1/g
```

- `foobar` 变为 `barfoo`

## 4. 前瞻与后顾（Lookahead/Lookbehind，含局部范围）

Vim 不支持标准的 lookahead/lookbehind，但可以用 `\zs` 和 `\ze` 实现类似效果。

- `\zs`：设置匹配开始
- `\ze`：设置匹配结束

### 前瞻（模拟）

**只替换 `foo` 后面的 `bar` 为 `BAZ`**

```vim
:%s/foo\zsbar/BAZ/g
```

- `foobar` 变为 `fooBAZ`

#### 局部范围前瞻

```vim
:10,20s/foo\zsbar/BAZ/g
```

- 只在第 10~20 行内，把 `foo` 后面的 `bar` 替换为 `BAZ`

---

### 后顾（模拟）

**只替换 `bar` 前面的 `foo` 为 `FOO`**

```vim
:%s/foo\ze bar/FOO/g
```

- `foo bar` 变为 `FOO bar`

#### 局部范围后顾

```vim
:'<,'>s/foo\ze bar/FOO/g
```

- 只在选中行，把 `foo` 替换为 `FOO`，但只替换后面跟着 `bar` 的 `foo`

## 5. 常用例子

### 查找所有以 test 开头的行

```vim
/^test
```

- 匹配所有以 `test` 开头的行

### 替换所有数字为 X

```vim
:%s/\d/X/g
```

- `a1b2c3` 变为 `aXbXcX`

### 删除所有空行

```vim
:g/^$/d
```

- 删除所有完全为空的行

### 交换每行的两个单词

```vim
:%s/\(\w\+\)\s\+\(\w\+\)/\2 \1/g
```

- `hello world` 变为 `world hello`

### 只替换 foo 后面的 bar

```vim
:%s/foo\zsbar/BAZ/g
```

- `foobar` 变为 `fooBAZ`

### 匹配并删除所有以 // 开头的注释行

```vim
:g/^\/\//d
```

- 删除所有以 // 开头的注释行

### 匹配所有不含数字的行

```vim
/v\d/d
```

- 删除所有包含数字的行，保留不含数字的行

### 只在 20~30 行，将所有数字替换为 X

```vim
:20,30s/\d/X/g
```

### 只在选中行，把 `hello` 后面的 `world` 替换为 `VIM`

```vim
:'<,'>s/hello\zsworld/VIM/g
```

### 如果要**复制**当前行到第34行之后

- `:.t34`  
  其中 `t` 是 `:copy` 的缩写，表示**复制**，不会删除原行。

---

### 如果要**复制到第34、36、38行之后**

你可以依次执行：

```vim
:.t34
:.t36
:.t38
```

或者用一次命令批量复制（Vim/Neovim 支持逗号分隔的目标行号）：

```vim
:.t34 | .t36 | .t38
```

每条命令的含义：

- `:.t34`：复制当前行到第34行之后
- `:.t36`：复制当前行到第36行之后
- `:.t38`：复制当前行到第38行之后

---

**注意：**  
每次复制后，行号会发生变化，后续目标行号可能需要调整。如果你想始终复制到原始的34、36、38行之后，建议**从大到小**依次复制，避免行号偏移：

```vim
:.t38 | .t36 | .t34
```

这样可以保证每次插入都在正确的位置。

---

**总结：**

- 复制到34、36、38行之后：  
  `:.t38 | .t36 | .t34`（推荐，避免行号偏移）

- 复制到单一行之后：  
  `:.t34`

`:!xxd` 是一个 Vim 操作命令，它结合了两个部分：

## 命令分解

- `!`：在 Vim 中执行外部命令
- `xxd`：一个十六进制转储工具，用于以十六进制格式显示文件内容

## 功能说明

当你在 Vim 中执行 `:!xxd` 时，它会：

1. **调用外部工具**：运行系统的 `xxd` 命令
2. **显示十六进制**：将当前文件内容以十六进制格式显示
3. **分屏显示**：通常会在新的窗口或分屏中显示结果

## 实际效果示例

如果文件包含文本 "Hello"，执行 `:!xxd` 会显示类似：

```
00000000: 4865 6c6c 6f0a                                Hello.
```

- 左边：字节偏移量（00000000）
- 中间：十六进制表示的字节（48 65 6c 6c 6f 0a）
- 右边：对应的 ASCII 字符（Hello.）

## 常用变体

- `:%!xxd`：将整个文件转换为十六进制显示（替换缓冲区内容）
- `:'<,'>!xxd`：将选中的文本转换为十六进制显示

## 实用场景

1. **二进制文件编辑**：查看和编辑二进制文件
2. **字符编码分析**：检查文件的字符编码和特殊字符
3. **文件结构分析**：分析文件头和数据结构
4. **调试**：查看不可见字符或文件格式问题

## 退出和恢复

- 如果使用 `:%!xxd` 转换了整个文件，可以使用 `:%!xxd -r` 恢复为原始格式
- 如果只是查看，关闭分屏窗口即可返回正常编辑

这是一个非常强大的工具，特别适合处理二进制文件或进行低级文件分析。

先简要说下：vimdiff 就是“以差异方式打开多个文件/版本”，核心是几个打开方式 + 窗口/跳转/合并操作。

**一、常见打开方式**

在终端里：

```bash
# 比较两个文件
vimdiff file1 file2

# 用 diff 语法等价：
vim -d file1 file2

# 比较三个文件（常用于合并）
vimdiff base ours theirs
```

在 Vim/Neovim 里已有一个文件时：

```vim
:diffthis          " 当前窗口加入 diff
:vsplit other.c    " 右侧竖分屏打开
:diffthis          " 右侧也加入 diff

" 或直接：
:vert diffsplit other.c
```

**二、在不同窗口间跳转**

- `Ctrl+w h/j/k/l`：在左/下/上/右窗口间切换
- `Ctrl+w w`：在窗口间循环切换

**三、在差异块之间跳转**

- `[c`：跳到上一个 diff 块（chunk）
- `]c`：跳到下一个 diff 块

配合 `zz` 可把当前差异居中：

```vim
]czz   " 到下一个差异并居中
[czz   " 到上一个差异并居中
```

**四、拷贝/合并差异**

在 vimdiff 里常用“从别的窗口把当前差异拷过来”：

- `do`（diff obtain）：从“其他窗口”取得改动到当前窗口
    - 光标所在的这个差异块，会被替换成另一侧的版本。
- `dp`（diff put）：把当前窗口的改动“放到”其他窗口

所以在二路 diff 时通常是：

- 在 A 窗口光标定位到一个差异 → `do`：把 B 的内容拿到 A
- 在 A 窗口光标定位到一个差异 → `dp`：把 A 的内容覆盖 B

如果是三路（`base / ours / theirs`）合并，一般放在中间窗口（合并结果）上，用 `do/dp` 从左右两个窗口“吸”和“推”。

**五、折叠与刷新**

- `zo` / `zc`：打开/关闭折叠（diff 会自动把无关行折叠起来）
- `:diffupdate`：手动重新计算 diff（编辑了很多内容后用）

**六、退出与保存**

- `:w`：保存当前窗口文件
- `:wa`：保存所有窗口文件
- `:q` / `:qa`：退出当前 / 所有窗口（有未保存会提示）
- `:wqa`：保存全部并退出

**七、简单示例：对比并合并两个配置文件**

```bash
vimdiff old.conf new.conf
```

在里面：

1. 用 `]c` / `[c` 浏览各处差异；
2. 决定以 new.conf 为准时，在 `old.conf` 窗口中用 `do`；
3. 决定以 old.conf 为准时，在 `new.conf` 窗口中用 `dp`；
4. 合并完 `:wa` 保存，`:qa` 退出。
