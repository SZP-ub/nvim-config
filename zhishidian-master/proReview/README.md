## 示例范式（以通讯录项目为例）

# PhoneBook

## 项目简介

PhoneBook 是一个用 C 语言实现的简易通讯录管理程序，支持添加、查询、修改、删除联系人信息，并实现信息持久化存储，适合学习 C 语言基础和模块化编程。

## 目录结构

```
phoneBook/
├── docs/
├── src/
│   ├── main.c
│   ├── telephon.c
│   └── telephon.h
```

可以用命令`tree -L 2 | vim`快速生成直接粘贴复制。

## 快速开始

### 依赖环境

- GCC/Clang 支持 C11
- Linux/Windows/MacOS

### 安装与编译

```shell
cd phoneBook/src
gcc -o phonebook main.c telephon.c
```

或使用 CMake：

```shell
mkdir build
cd build
cmake ..
make
```

### 运行方法

```shell
./phonebook
```

## 使用说明

启动后根据菜单提示进行操作，包括添加、查询、修改、删除联系人等。

## 单元测试

推荐使用 CMocka/Unity 等框架，集成测试见 test/ 目录。

```shell
ctest  # CMake 集成测试
```
