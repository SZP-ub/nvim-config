概览（构成规则）

- 示位词由「こ/そ/あ/ど」+ 词尾构成，表示“靠说话人 / 靠听话人 / 都不靠 / 疑问”的对立关系。
- 常见搭配（按词性）：
    - 指示代词（代替名词）：これ / それ / あれ / どれ
    - 指示形容词（修饰名词）：この / その / あの / どの + 名词
    - 地点词：ここ / そこ / あそこ / どこ
    - 指向/礼貌用：こちら / そちら / あちら / どちら
    - 口语/方向：こっち / そっち / あっち / どっち

含义与区别（核心点）

1. こ（これ・この・ここ・こっち / こちら）
    - 指靠近说话人的事物或位置（“这儿/这个”）。
    - 例：これは私の本です。（这是我的书 — 在我这边 / 我拿着 / 我刚提到的）
    - 这里也可用于刚要提出的东西或手里拿着的东西。

2. そ（それ・その・そこ・そっち / そちら）
    - 指靠近听话人的事物或位置，或在对话中已被提到、听者熟知的事物（“那（你那边/前面提到的）”）。
    - 例：その本はあなたのですか。（那本书是你的？ — 书靠近你或已在话题中）
    - 在对话里，そ-常作“对方那边／前文提到的东西”的指代。

3. あ（あれ・あの・あそこ・あっち / あちら）
    - 指离说话人和听话人都较远的事物或位置（“那（远处）”）。
    - 例：あの山は富士山です。（那座山是富士山 — 两人都不近）
    - 常用于远处或双方都看得到但都不靠近的东西。

4. ど（どれ・どの・どこ・どっち / どちら）
    - 疑问用，表示“哪个/哪里/哪边/哪一位”。
    - 例：どれがあなたのですか。（哪个是你的？）

示例对照（常见句型）

- 指示代词（代替名词）
    - これ・それ・あれ・どれ
    - 例：これは美味しいです。（这个很好吃。）
    - 例：それは違います。（那（你说的/前面提到的）不对。）

- 指示形容词 + 名词
    - この本 / その本 / あの本 / どの本
    - 例：この本は面白いです。（这本书有趣。）
    - 例：あの店に行きましょう。（去那家（远处的/双方都知道的）店吧。）

- 地点词
    - ここ（这里） / そこ（那里，靠听者或前文） / あそこ（那里，远处） / どこ（哪里）
    - 例：ここで待ってください。（请在这里等。）

- 礼貌/指向（更正式或表示方向/对方）
    - こちら（这边/我方/请这位） / そちら / あちら / どちら（哪一边/哪位，礼貌）
    - 例：こちらが田中さんです。（这位是田中先生。 — 用于介绍，较礼貌）
    - 例：どちらから来ましたか？（您从哪里来的？ — 礼貌问法）

- 口语化／方向感（更随意）
    - こっち / そっち / あっち / どっち
    - 例：こっちに来て！（过来这边！）

补充要点与常见疑问

- 「それ」不仅表示空间上的“靠近听话人”，还能指“在谈话中已经提到的事物/概念”。所以即使物理上不在听者旁，也可以用「それ」。
    - 例：A: 昨日の映画、どうだった？ B: それはすごく良かったよ。（那部电影非常好 —— 指前文提到的电影）
- 指人时通常用「この人／その人／あの人」而不是单用「これ／それ」。
- Politeness：商务或礼貌场合常用「こちら／そちら／あちら／どちら」代替普通的こ/そ/あ/ど表达。
- 时间上的用法：これから（从现在起）、それから（然后/接着）、これまで（到现在为止）等，示位词也有时标/时态衍生用法。

速记小表（思路）

- こ- ：靠近说话人（我这儿／我这边）
- そ- ：靠近听话人或已提到的（你那儿 / 前文）
- あ- ：离双方都远（那边/远处）
- ど- ：疑问（哪个/哪里）
