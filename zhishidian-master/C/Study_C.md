## 一、命名规范

### 1. 变量命名

- 变量名一般用小写字母，多个单词用下划线分隔（如 `value`, `total_sum`）。
- 变量名要简短且有意义，能反映变量用途，适合局部变量。
- 避免与C语言关键字冲突（如 `int`, `char`, `for` 等）。

### 2. 结构体命名

- 结构体类型名一般首字母大写或每个单词首字母大写（如 `Stack`, `Node`）。
- 结构体成员变量用小写字母（如 `data`, `top`, `next`）。
- 枚举首单词小写，第二各单词首字母大写，成员变量大写。

### 3. 函数命名

- 函数名一般用小写字母，多个单词用下划线分隔（如 `init_stack`, `push`, `is_empty`）。
- 常采用“动词+对象”或“is+形容词”风格，能体现函数功能。

### 4. 常量和宏命名

- 常量和宏用全大写字母，单词间用下划线分隔（如 `MAX_SIZE`, `PI`）。

### 5. 指针变量命名

- 可在变量名前加 `p` 或 `ptr` 前缀（如 `pNode`, `ptr_data`），以增强可读性，但不是强制要求。

## 二、C语言变量类型

### 1. 基本数据类型及修饰符

| 类型      | 大小（字节） | 取值范围                                   | 输入输出格式 | 说明                          |
| --------- | ------------ | ------------------------------------------ | ------------ | ----------------------------- |
| int       | 4            | -2147483648 ~ 2147483647                   | `%d`         | 整型，支持加减乘除取模        |
| float     | 4            | ~3.4E-38 ~ 3.4E+38                         | `%f`         | 单精度浮点，约6~7位有效数字   |
| double    | 8            | ~1.7E-308 ~ 1.7E+308                       | `%lf`        | 双精度浮点，约15~16位有效数字 |
| char      | 1            | -128 ~ 127（signed），0 ~ 255（unsigned）  | `%c`         | 字符型，ASCII码               |
| long long | 8            | -9223372036854775808 ~ 9223372036854775807 | `%lld`       | 长长整型                      |

#### 修饰符

- `short`：短整型，通常占 2 字节。`short int x;`，`%hd`，取值范围 -32768 ~ 32767
- `long`：长整型，通常占 4 或 8 字节。`long int y;`，`%ld`
- `unsigned`：无符号型，只能存储正数。`unsigned int u;`，`%u`，取值范围 0 ~ 4294967295
- `signed`：有符号型，可存储正负数。`signed char ch;`

**示例：**

```c
int a = 10;
float b = 3.14f;
double c = 3.1415926;
char d = 'A';
long long x = 9223372036854775807LL;
unsigned int b = 4000000000;
short c = -32000;
long d = 2000000000;
```

### 2. 构造类型

- **数组**：一组相同类型的数据。`int arr[10];`
- **结构体（struct）**：可存储不同类型的数据。
  ```c
  struct Person {
      char name[20];
      int age;
  };
  ```
- **联合体（union）**：多个成员共用同一块内存。
  ```c
  union Data {
      int i;
      float f;
      char str[20];
  };
  ```
- **枚举（enum）**：枚举常量集合。
  ```c
  enum Week {Mon, Tue, Wed, Thu, Fri, Sat, Sun};
  ```

### 3. 指针类型

- 用于存储变量的地址。`int *p;`
- 大小：4 字节（32 位），8 字节（64 位）
- 输入输出：`%p`

### 4. void 类型

- 表示无类型，常用于函数返回值或指针。`void func();`、`void *ptr;`

## 三、字符串和字符初始化

### 1. 字符初始化

- 字符类型用 `char`，初始化时用单引号：
  ```c
  char ch = 'A';   // 字符A
  char ch2 = 65;   // ASCII码65，即'A'
  char ch3 = '\n'; // 特殊字符
  ```
- 注意：字符常量必须用单引号 `' '`，不能用双引号。

### 2. 字符串初始化

- 字符串是字符数组，以 `\0` 结尾。
  ```c
  char str1[] = "hello";      // 自动加上 '\0'
  char str2[6] = "hello";     // 指定长度，包含 '\0'
  char str3[] = {'h','e','l','l','o','\0'}; // 用字符数组初始化
  ```
- 字符串常量用双引号 `" "`，字符数组要有足够空间存放结尾的 `\0`。

## 四、进制输入输出与转换

### 1. 输入输出格式

- **十进制**：`scanf("%d", &a);`，`printf("%d", a);`
- **八进制**：`scanf("%o", &a);`，`printf("%o", a);`
- **十六进制**：`scanf("%x", &a);`，`printf("%x", a);`
- **二进制**：C 标准库无直接支持，需手动实现

**二进制输出示例：**

```c
void print_binary(unsigned int n) {
    for (int i = 31; i >= 0; i--) {
        printf("%d", (n >> i) & 1);
    }
    printf("\n");
}
```

### 2. 进制转换方法

- **十进制转二/八/十六进制**：不断除以2/8/16，逆序取余
- **二/八/十六进制转十进制**：直接用 `scanf` 的格式符输入即可

**十进制小数与二进制转换：**

- 整数部分：不断除以2取余
- 小数部分：不断乘以2，取整数部分作为二进制位

## 五、float 和 double 的精度与内存表示

### 1. 内存结构（IEEE 754 标准）

- **float（32位）**：1 位符号位，8 位指数位，23 位尾数
- **double（64位）**：1 位符号位，11 位指数位，52 位尾数

### 2. 精度丢失

- float 精度约 6~7 位，double 精度约 15~16 位
- 由于二进制无法精确表示大多数十进制小数，会出现精度误差

## 六、数据溢出及其处理（内存角度解析）

### 1. 整型溢出

- 有符号整型采用补码存储。溢出时，最高位（符号位）变化，导致数值回绕。例如 `int` 最大值 2147483647（0x7FFFFFFF）+1，变为最小值 -2147483648（0x80000000）。
- 无符号整型存储为原码，溢出时回到0。例如 `unsigned int` 最大值 4294967295（0xFFFFFFFF）+1，变为0（0x00000000）。

**内存原理：**

- 计算机只存储固定位数，超出部分被截断。
- 有符号整型用补码表示，最高位为符号位。溢出时，二进制位重新解释为另一数值。

**示例：**

```c
int a = 2147483647;
a = a + 1; // 变成 -2147483648
unsigned int b = 4294967295U;
b = b + 1; // 变成 0
```

### 2. 浮点型溢出

- 超过最大表示范围时，结果为 `inf`（无穷大），在内存中指数全为1，尾数全为0。
- 小于最小正数时，结果为 `0` 或 `-0`，在内存中全为0或符号位为1。

**示例：**

```c
float f = 1e39f; // 超出 float 范围，变为 inf
printf("%f\n", f); // 输出 inf
```

### 3. 溢出后的表现和原因

- 表现：数值回绕或变为无穷大、0。
- 原因：内存位数有限，超出部分被截断或特殊处理（如 IEEE 754 的 inf）。
- 内存上：溢出后，存储的二进制值被重新解释为另一数值。

### 4. 溢出的处理与修正

- 避免溢出：使用更大类型（如 long long），或在运算前判断是否会溢出。
- 无符号类型：注意回绕特性，避免负数参与运算。
- 浮点溢出：可用 `isinf()`、`isnan()` 检查结果。
- 安全库函数：如 `strtol`、`strtoll` 可检测溢出。

**示例：**

```c
#include <limits.h>
if (a > INT_MAX - b) {
    // 溢出风险
}
```

## 七、整型的原码、反码、补码

### 1. 原码、反码、补码定义与举例

- 原码：最高位为符号位（0正1负），其余位为绝对值。
- 反码：正数反码等于原码，负数反码为原码符号位不变，其余位取反。
- 补码：正数补码等于原码，负数补码为反码加1。

| 数值 | 原码      | 反码      | 补码      |
| ---- | --------- | --------- | --------- |
| +5   | 0000 0101 | 0000 0101 | 0000 0101 |
| -5   | 1000 0101 | 1111 1010 | 1111 1011 |

### 2. 为什么用补码？

- 统一加减法运算，简化硬件设计。
- 唯一零表示，补码只有一个零。
- 溢出处理简单。

### 3. C语言实际应用

- 有符号整型负数以补码形式存储。

## 九、C 语言输入函数详解与安全性

### 1. scanf() 函数

### 2. fgets() 与 sscanf() 组合

- 先用 `fgets()` 读取，再用 `sscanf()` 解析，安全且灵活。

## 三十二、fgets() 和 sscanf() 代码详解

- `fgets` 逐行读取文件内容，自动加 `\0`，不需要初始化缓冲区。
- `sscanf` 从字符串中提取数据，格式灵活，适合解析结构化文本。
- `%d` 读取一个整数，遇到非数字就停。

## 三十三、%c 读取空白符的处理

- `%c` 默认不会跳过空白符，直接读取当前位置字符。
- 想跳过空白符，格式写 `" %c"`。
- 用 `strchr(" \t\n", op)` 判断是否为空白符。

```c
while (fgets(tmp, sizeof(tmp), fptr_read) != EOF) {
    cnt++;
}
```

### 问题分析

- 判断条件错误：`fgets` 的返回值是指向缓冲区的指针，读取成功返回该指针，失败或文件末尾返回 `NULL`。
- `EOF` 是整型常量（通常为 -1），用于 `getc`、`fgetc`、`scanf` 等函数的返回值判断。
- 用 `fgets(...) != EOF` 判断是错误的，应该判断 `!= NULL`。

**正确写法：**

```c
while (fgets(tmp, sizeof(tmp), fptr_read) != NULL) {
    cnt++;
}
```

## 三十四、strcspn() 和 strpbrk() 字符串处理函数

### 1. `strcspn()`

- 查找字符串中第一个出现在指定集合中的字符位置，返回下标，没找到返回字符串长度。
- 常用于去除字符串中的特定字符（如换行符、空格等）。

**示例：**

```c
char str[] = "hello, world\n";
size_t pos = strcspn(str, "\n");
str[pos] = '\0'; // 去除换行符
```

### 2. `strpbrk()`

- 查找字符串中第一个属于指定集合的字符，返回指针，没找到返回 NULL。
- 常用于分割字符串、提取特定内容。

**示例：**

```c
char str[] = "123+456";
char *p = strpbrk(str, "+-*/");
if (p) {
    printf("第一个运算符: %c\n", *p);
}
```

**对比：**

| 函数    | 返回值类型 | 作用                                                   |
| ------- | ---------- | ------------------------------------------------------ |
| strcspn | size_t     | 返回 s1 中第一个属于 s2 的字符下标，没找到返回 s1 长度 |
| strpbrk | char\*     | 返回 s1 中第一个属于 s2 的字符指针，没找到返回 NULL    |

## 三十五、结构体和数组初始化方式

### 1. 结构体定义建议

你的 `char name;` 只能存一个字符，通常名字要用字符串数组：

```c
typedef struct Person {
    char name[32]; // 推荐长度可根据实际调整
    int  age;
} Person;
```

### 2. 初始化结构体数组

#### 方法一：直接初始化

```c
Person persons[3] = {
    {"tina", 18},
    {"tom", 20},
    {"lucy", 22}
};
```

#### 方法二：逐个赋值

```c
Person persons[3];
strcpy(persons[0].name, "tina");
persons[0].age = 18;

strcpy(persons[1].name, "tom");
persons[1].age = 20;

strcpy(persons[2].name, "lucy");
persons[2].age = 22;
```

### 3. 修改结构体数组的值

比如修改第2个人的名字和年龄：

```c
strcpy(persons[1].name, "jack");
persons[1].age = 25;
```

### 4. 指针方式（不推荐直接用指针数组）

如果你确实要用指针数组：

```c
Person *persons[3];
for (int i = 0; i < 3; ++i) {
    persons[i] = malloc(sizeof(Person));
}
strcpy(persons[0]->name, "tina");
persons[0]->age = 18;
```

用完记得释放内存：

```c
for (int i = 0; i < 3; ++i) {
    free(persons[i]);
}
```

### 5. 你的代码问题

```c
Person* person[3] = {person[0]->name = "tina", person[0]->age = "18"};
```

- 这样写是错误的，不能这样初始化和赋值。

## 三十六、数组和指针比较

- 数组比较的是数组的首地址，因为字符串常量会被复制到数组的独立内存空间，每个数组的地址不同。
- 指针比较的是指针变量的内容，即指针指向的地址。字符串常量通常只分配一份，多个指针可能指向同一个常量地址。

## 三十七、数组和指针在函数传参时的区别

- 数组作为参数，实际上传递的是数组首元素的地址，但本质上还是一个指针。
- 数组本身不会自动传递长度，函数需要额外传递长度参数。
- 指针作为参数，直接传递的是指向某个内存区域的地址（如字符串常量）。
- 字符串指针通常以 `\0` 结尾，函数可以通过遍历直到遇到 `\0` 来判断字符串结束，无需额外传递长度。

| 方式 | 是否需传长度 | 结束标志       | 典型用法             |
| ---- | ------------ | -------------- | -------------------- |
| 数组 | 需要         | 无（需传长度） | 二进制数据、定长数组 |
| 指针 | 不需要       | `\0` 结尾      | 字符串处理           |

---

## 三十八、指针变量本身与常量区

- 指针变量本身分配在栈上（局部变量），指针指向的内容（如字符串常量）通常存储在常量区（只读数据段）。
- 指针变量的地址：在栈上
- 指针指向的数据（如 `"abc"`）：在常量区

---

## 三十九、指针和数组的运算与格式化输出

- `name` 是一个指针数组，每个元素都是 `char*`，指向一个字符串常量。
- `name + 1`：指向第二个元素（`"yzg"`）。
- `*(name + 1)`：取出第二个元素的值，即指向 `"yzg"` 的指针。
- `*(name + 1) + 2`：在 `"yzg"` 的基础上偏移2个字符，指向 `"g"`（即 `"g"` 字符串的首地址）。
- `*(*(name + 1) + 2)`：先偏移到 `"g"`，再取出该地址的字符，即 `'g'`。

| 表达式               | 类型   | 输出格式 | 结果  |
| -------------------- | ------ | -------- | ----- |
| `name[1][2]`         | char   | `%c`     | `'g'` |
| `*(*(name + 1) + 2)` | char   | `%c`     | `'g'` |
| `*(name + 1) + 2`    | char\* | `%s`     | `"g"` |

- `%c` 用于输出单个字符。
- `%s` 用于输出字符串（从某个字符开始直到遇到 `\0`）。

## 四十、跳转到绝对地址执行

- 可以通过函数指针或强制类型转换让程序跳到绝对地址执行，但这种做法非常危险，容易导致程序崩溃或安全问题。

```c
void (*func_ptr)() = (void (*)())0x12345678; // 绝对地址
func_ptr(); // 跳转执行
```

- 该地址必须是可执行代码的起始地址，否则会崩溃。
- 现代操作系统通常禁止这种操作（内存保护），只有嵌入式或裸机环境才常见。
- 不建议在普通应用程序中使用。

## 四十一、volatile 关键字详解

### 1. 基本作用

- `volatile` 修饰的变量，编译器不会对其进行优化，每次访问都必须从内存中读取，而不是用寄存器中的缓存值。
- 适用于变量可能被外部事件（如硬件、其他线程、中断等）修改的场景。

### 2. 典型应用场景

- 硬件寄存器映射
- 多线程/中断通信
- 自旋锁等同步机制

### 3. 语法用法

- 可以修饰基本类型、指针、结构体成员等：

```c
volatile int a;
volatile char *p;
struct S { volatile int x; };
```

### 4. 编译器行为

- 禁止优化，保证可见性。

### 5. 与 const 的区别

- `const`：只读，不能修改。
- `volatile`：随时可能被修改，必须每次都读内存。
- 可以组合使用：`const volatile int a;` 表示“只读但随时可能变化”。

### 6. 注意事项

- `volatile` 不能保证原子性或线程安全，只保证可见性。
- 对于多线程同步，通常还需要配合互斥锁、原子操作等机制。
- 滥用 `volatile` 会影响性能，因为每次都强制访问内存。

### 7. 相关标准

- C89/C99/C11 标准都支持 `volatile`。
- 在嵌入式开发、驱动开发、操作系统等底层场景非常常用。

### 8. 示例

```c
volatile int status;
while (status == 0) {
    // 等待外部事件改变 status
}
```

## 四十五、GDB 内存查看命令

- `x/4xb b`：以字节为单位显示，从地址 `b` 开始，显示4个字节。
- `x/4xw b`：以字（4字节）为单位显示，从地址 `b` 开始，显示4个字。
- `x/8xw`：以4字节为单位显示8个 word。
- `x/4xb` 展示原始字节序列，`x/4xw` 展示按字（4字节）拼接后的值。
- 例如，`0x12345678` 的字节序是 `0x78 0x56 0x34 0x12`（小端序），`x/4xw` 就把这4个字节拼成一个32位整数显示。

## 四十六、指针运算与类型转换

- `(int)a + 1` 不是数组元素偏移，而是字节偏移，导致指针错位，访问非法内存。
- `p2[0]` 和 `*(int*)((int)a+1)` 都是访问非法地址，gdb报错。
- gdb显示不一样，是因为命令格式不同，底层处理略有差异，但本质都是非法访问。
- 不要用 `(int)a + 1` 这种写法做指针运算，应该用 `a + 1` 或 `&a[n]` 这样标准的指针偏移。

## 四十七、位域的最大存储值与内存分布

- `int i:4` 最大存储值是 15（无符号），只占用一个 int 的4位，其余位可以被其它位域成员或填充。
- 多个位域成员会被打包在同一个 `int` 里，直到用完 32 位。
- 在 `x/8xw` 查看时，显示的是整个 int（4字节），位域只占其中一部分。

## 四十八、volatile 变量的多次读取问题

- `volatile` 关键字表示 `ptr` 指向的值可能随时被外部改变（如硬件寄存器、多线程等），编译器不会优化对它的访问。
- 在 `return *ptr * *ptr;` 中，`*ptr` 被读取了两次。如果 `*ptr` 的值在两次读取之间发生了变化（比如硬件或其他线程修改），结果可能不是预期的平方值。
- 更安全的写法是先读取一次再计算：

```c
int square(volatile int* ptr) {
    int val = *ptr;
    return val * val;
}
```

## 四十九、二进制与十六进制的关系

- 4个位（二进制位）刚好可以表示一个十六进制符号。
- 二进制有 2 个状态：0 和 1
- 4 位二进制可以表示的状态数是 2⁴ = 16
- 十六进制有 16 个符号：0, 1, 2, ..., 9, A, B, C, D, E, F
- 每4个位二进制直接对应一个十六进制符号。
- 在二进制转十六进制时，就是每4位分组转换为一个十六进制字符。

---

## 五十、字符编码与字节关系

- 如果你说的是十六进制符号，那么两个十六进制符号确实等于一个字节。
- 一个字节 = 8位
- 一个十六进制符号（0-9, A-F）可以表示4位
- 两个十六进制符号 = 4位 + 4位 = 8位 = 1字节
- 十六进制 `FF` = 二进制 `1111 1111` = 十进制 255 = 1字节
- 这里的“符号”指的是十六进制的字符（0~F），不是随意的字符。
- 如果是其他编码，比如ASCII，每个英文字符通常占1字节，但不是所有字符都能直接这么换算。
- 如果是UTF-8编码，一个汉字可能占2~4字节。
- 在十六进制表示法中，两个符号就是一个字节。
- 其他情况下，要根据实际编码方式判断。

## 1. 类型再分析

```c
char* const *(*nest)();
```

- `nest` 是一个函数指针，可以指向别的同类型函数（没有被const修饰）。
- `nest()` 调用后得到 `char* const *`，即指向“常指针”的指针。
- `*nest()` 得到的是 `char* const`，即“常指针”。
- `*nest()[i]` 或 `nest()[i]` 是数组形式访问第 i 个元素，类型为 `char* const`。

---

## 2. 限制关系

- **nest**：可以更改指向其他函数（无const限制）。
- **nest()**：返回值类型为 `char* const *`，可以指向其他 `char* const` 数组。
- **nest()[i] / \*nest()[i]**：类型为 `char* const`，**不能修改指针本身的指向**（即不能赋值 nest()[i] = ...），但可以通过它修改其指向的内容（如字符串内容）。

---

## 3. 纯指针写法等价关系

### 数组形式

```c
nest()[i]  // 访问第i个元素，类型是char* const
```

### 指针形式

```c
* (nest() + i)  // 也是访问第i个元素，类型是char* const
```

- 解释：
  - `nest()` 返回 `char* const *`，即一个指针。
  - `nest() + i` 指向第 i 个元素。
  - `*(nest() + i)` 解引用，得到第 i 个 `char* const`。

### 内容访问

如果你要访问第 i 个字符串的第 j 个字符，可以写成：

```c
nest()[i][j]      // 或
* (nest() + i) [j]  // 或
* (*(nest() + i) + j)
```

---

## 4. 总结

- `nest()[i]` 和 `*(nest() + i)` 完全等价，都是访问第 i 个元素，类型是 `char* const`。
- 不能写 `nest()[i] = ...`，因为每个元素是常指针。
- 可以写 `nest()[i][j] = ...` 或 `*(*(nest() + i) + j) = ...`，因为可以修改指向的数据内容。

---

### 例子

```c
#include <stdio.h>

char str1[] = "Hello";
char str2[] = "World";
char* const arr[] = {str1, str2};

char* const * getArr() { return arr; }

int main() {
    char* const *(*nest)() = getArr;
    // 纯指针访问
    printf("%s\n", *(nest() + 1));         // World
    (* (nest() + 1))[0] = 'w';             // World -> world
    printf("%s\n", *(nest() + 1));         // world

    // 等价于数组方式
    printf("%s\n", nest()[1]);             // world

    return 0;
}
```
