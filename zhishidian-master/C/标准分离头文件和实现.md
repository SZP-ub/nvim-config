好的，下面细化 C 语言头文件（.h）与实现文件（.c，main.c）分离的标准，并通过对比说明什么声明放头文件、什么放 main.c。

---

## 一、头文件（.h）和实现文件（.c）的作用

| 文件类型     | 主要作用                                                      |
| ------------ | ------------------------------------------------------------- |
| 头文件(.h)   | 提供接口声明，供其他文件引用，描述“能做什么”                  |
| 实现文件(.c) | 提供具体实现，描述“怎么做”，包含函数体、变量定义、main 函数等 |

---

## 二、头文件和实现文件内容对比

| 内容类型         | 头文件(.h)      | 实现文件(.c/main.c)           | 说明                                         |
| ---------------- | --------------- | ----------------------------- | -------------------------------------------- |
| 函数声明         | 放              | 不放（除非本文件私有 static） | 让其他文件能调用本文件实现的函数             |
| 函数实现         | 不放            | 放                            | 只在实现文件写函数体                         |
| 结构体/枚举声明  | 放              | 不放                          | 让其他文件能用这些类型                       |
| 宏定义           | 放              | 可放（仅本文件用的宏）        | 供多文件共享的宏放头文件，私有宏可放实现文件 |
| typedef 类型定义 | 放              | 不放                          | 让其他文件能用 typedef 类型                  |
| 全局变量声明     | 放（用 extern） | 放（定义，不加 extern）       | 头文件用 extern 声明，.c 文件定义变量        |
| 静态变量/函数    | 不放            | 放（加 static）               | 只在本文件用，不暴露给外部                   |
| main 函数        | 不放            | 只放 main.c                   | 程序入口，只能有一个 main                    |

---

## 三、举例对比

### 1. 头文件 foo.h

```c
#ifndef FOO_H
#define FOO_H

// 函数声明
void foo(int x);

// 结构体声明
typedef struct {
    int a;
    int b;
} Foo;

// 宏定义
#define MAX_SIZE 100

// 全局变量声明
extern int global_count;

#endif
```

### 2. 实现文件 foo.c

```c
#include "foo.h"

// 全局变量定义
int global_count = 0;

// 函数实现
void foo(int x) {
    // ...
}

// 只在本文件用的静态函数
static void helper() {
    // ...
}
```

### 3. 主文件 main.c

```c
#include "foo.h"

int main() {
    Foo f;
    foo(42);
    return 0;
}
```

## 四、常见错误对比

| 错误做法（不推荐）            | 正确做法（推荐）                                  | 说明                     |
| ----------------------------- | ------------------------------------------------- | ------------------------ |
| 在 main.c 里重复写 foo() 声明 | 在 foo.h 里声明 foo()，main.c 只 #include "foo.h" | 保证声明唯一、易维护     |
| 在 foo.h 里写 foo() 实现      | 只在 foo.c 里写 foo() 实现                        | 头文件只做声明，不做实现 |
| 在 foo.c 里定义结构体         | 在 foo.h 里定义结构体                             | 结构体要让外部可见       |
| 在 foo.h 里定义全局变量       | 在 foo.h 里用 extern 声明，在 foo.c 里定义        | 防止多重定义             |

---

## 五、总结

- **头文件（.h）**：放声明、类型、宏、extern，全局可见的接口。
- **实现文件（.c）**：放实现、定义、main 函数、静态内容，仅本文件可见。
- **main.c**：只放 main 函数和本文件私有实现，不放接口声明。
